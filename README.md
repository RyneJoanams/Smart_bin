# Smart_bin
This is a group 9 project on a a smart bin solution that enables a waste bin to open up without a manual lid lift. Intergrating the use of an arduino board, an ultrasonic sensor combinservo sensor to bring this project to life.

get to read and know of the different components using the links below:
Ultrasonic sensor - https://docs.wokwi.com/parts/wokwi-hc-sr04
servo motor - https://docs.wokwi.com/parts/wokwi-servo
Arduino UNO - https://docs.wokwi.com/parts/wokwi-arduino-uno
